### 2.3 铁律 7 精化（单点失败允许一次鉴别复跑）

| 项 | 内容 |
|---|---|
| **原铁律 7** | 「任一验证 FAIL → 立即停，报告现场与剩余未执行项，**不得继续后续阶段**」 |
| **精化后** | **单点失败**允许**一次**鉴别复跑；若复现，或失败**非单点**（≥2 项 / 涉及被演练对象本身），**立即停** |
| **"单点"判定** | 失败项数 = 1，且失败项与被演练对象（`src`/`tests` 的目录切换与哈希）**无因果关联** |
| **"鉴别复跑"上限** | 同一失败项最多 1 次隔离复跑（可附带 1 次全量复跑作为配对样本）；**不得循环复跑至绿** |
| **必须留证** | 首次失败的原始日志、复跑次数与结果、判定理由，全部写入报告 |
| **来源** | 本次演练中"前门禁性能用例偶发 + 后门禁 EPERM 偶发"的实际处置经验（演练报告 §2、§5.4） |

> **不得外推**：本精化**只适用于验证门禁的偶发失败鉴别**，不适用于 `rename` 失败、哈希不符、`live` 状态不明等**安全性判定**——那三类仍按"立即停、人工裁决"执行。
