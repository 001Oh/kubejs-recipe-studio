## 8. C7-F2、C3、REL-PKG 的验收关系

```
C7-F2 跨平台验证（1 条条件）
├── F2a 提交/备份：rename、权限、行分隔；提交/备份/回滚/只读失败
└── F2b listAndRead/ZIP：POSIX 句柄释放、并发、内容一致性
        ↑ 来自 OPT4-R1（已合并，不再单列）

REL-PKG（1 条条件，硬阻塞）
├── A 打包：dist:win 命令/退出码/产物
├── B 安装：安装→启动→扫描→升级→卸载
├── C 目录隔离 ← P2-PKGDIR（原独立条件，已并入）
└── D asar+worker 冒烟 ← 审计 C3（原遗漏，已并入）
        ↑ C 同时以 REL-VERIFY-PKGDIR 视图保留，避免合并后丢验收
```

- F2a/F2b、A/B/C/D 均为**验收动作**，不单独计数；状态分别记录。
- Windows 上既有验证**不被描述为** Linux/macOS 已通过。
