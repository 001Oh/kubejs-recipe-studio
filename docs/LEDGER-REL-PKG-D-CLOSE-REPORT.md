## 5. 本次关闭的对象与证据链

### D-1（asar 下 worker 可运行）

- **通过**，依据 `PACK-07`：
  1. 独立 asar Worker 探针（同 Electron 33.4.11 + 同一 `app.asar`）实测 `EXISTS=true`、`WORKER=created`、5 s 无 error；
  2. `if (!workerAvailable) return runInline()` ⇒ worker 为唯一分支；
  3. `new Worker` 无 try/catch，失败必然导致整次扫描失败，而扫描成功且无 `ERR_WORKER_PATH`。
- **必须记录的限定**：`stats.usedWorkers` 在该构建中**无直接外部观测出口**（IPC / 日志 / `CacheMeta` / `items.json` 全部没有），故判定为**三段实测链的推导**，不是字面取值。此限定已写进台账 §3.7 D 行。

### D-2（295-jar 冒烟 + 五项计数）

- **通过**，依据 `PACK-09`（选包依据 `PACK-08`）：
  - 基准包 `pc5-pack-1112`（只读，1,658 文件 / 295 jar）
  - `cacheHit = false`、终态 `index-ready`、`failedMods = 0`、扫描 38.8 s
  - 五项：**43,474 / 38,760 / 32,890 / 426 / 5,334 全部一致**

### D-3（D-1 失败时的错误证据）

- **不适用**：D-1 通过、无 worker 错误，未触发失败分支；未记录 `ERR_WORKER_PATH`、未提出 `asarUnpack` 方向、未修改任何构建配置。
