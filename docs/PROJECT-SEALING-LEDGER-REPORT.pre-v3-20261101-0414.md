> 此前用 `STUDIO_USER_DATA` 模拟两个 userData 的结果，**不能替代**真实安装版 + dev 并行测试。

### 7.3 REL-VERIFY-4K 的验收标准

日志详情区可读；长 detail 折行正常；无横向溢出；无关键内容被遮挡；保存实际截图作为证据。
