## 0. 使用说明

### 0.1 证据状态四级

| 状态 | 定义 |
| --- | --- |
| **A** | 本轮独立验证（本轮亲自读取源码/产物/日志并直接得出结论） |
| **B** | 历史验收（本轮核对报告原文与其引用的原始文件存在性及关键数值，**未重跑**） |
| **C** | 部分（只核对一部分，或证据链有中断） |
| **D** | 未验证（本轮无法核对，或历史本身缺失） |

### 0.2 强制限制声明

> **本矩阵中所有 B / C / D 项均不得被引用为 A 级结论。**
> 本轮受任务书 §1.4 约束（禁止构建、安装、卸载、启动、扫描、删改），**绝大多数运行时结论只能停留在 B**。B 的效力边界是「报告与其原始观测一致」，**不等于「本轮复现成功」**。
> **`cacheHit` 保持「未测量」**——本轮确认不得由 `cache.ts` 的静态逻辑推断为 `true`。
> **`REL-VERIFY-DUAL`（双击启动）/ `REL-VERIFY-4K` / 正常 GPU 路径 / `P2-DUALFORM` / `P2-POSIXPATH` 一律为 D**，不得写成已验证。

### 0.3 证据类型三分

| 类型 | 含义 | 效力 |
| --- | --- | --- |
| **运行时** | 真实进程/安装器/IPC 的实测输出（日志、DOM、返回值、照片/截图） | 最高 |
| **文件** | 磁盘上的字节级事实（SHA-256、文件计数、产物 VersionInfo、注册表值） | 高（可复核） |
| **静态** | 源码阅读/文本检索得出的结论 | 中（**不得冒充运行时**） |
