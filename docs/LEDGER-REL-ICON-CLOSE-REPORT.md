## 6. 关于"安装包未签名"

按要求**单独登记为分发风险，未纳入 REL-ICON 的关闭条件**：

- 证据：`.cache/pack-03/dist-win.log` 中 `• no signing info identified, signing is skipped  signHook=false cscInfo=null`（4 处，主程序 / elevate.exe / 卸载器 / 安装包各一次）；
- 影响：未签名安装包在 Windows 上会触发 SmartScreen「未知发布者」提示，企业分发可能被策略拦截；
- 位置：主台账 §8 第 8 项，等待负责人决定是否配置代码签名证书；
- **它既不是 REL-ICON 的关闭条件，也不构成 REL-ICON 关闭的例外**——REL-ICON 只覆盖"图标与打包前置资源"。
